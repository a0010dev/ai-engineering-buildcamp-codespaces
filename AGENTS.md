# Project instructions

## Environment

This project runs in GitHub Codespaces.

## Python

Use the project's existing Python environment and dependencies.

## OpenAI

The environment variable `OPENAI_API_KEY` is provided through
GitHub Codespaces secrets.

Never hardcode, print, log, or commit API keys.

## Development

- Prefer small, understandable changes.
- Do not modify unrelated files.
- Run relevant tests after changes.
- Explain architectural changes before making large refactors.

## Git

Do not commit or push unless explicitly requested.
